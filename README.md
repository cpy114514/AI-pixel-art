# AI Pixel Art

A simple pixel-art tool for making game sprites with AI.

You can generate pixel art image, edit the image and also make animation with AI.

## Latest release:

<https://github.com/cpy114514/AI-pixel-art/releases/tag/v1.0.4>

## Set up on your PC

1. Download `AI-Pixel-Art-Windows-Setup.exe` from the latest release
2. Do not download the GitHub `Source code` zip
3. Double-click the setup exe
4. Insert your own api-key, highly recomand faster module
5. try generate pixel art with AI
